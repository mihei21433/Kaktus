# Кактус

Цели, ежедневные задачи и прогресс участников под контролем модератора.
Мобильное приложение для Android и iOS и сервер.

```
mobile/   приложение (Expo, React Native, TypeScript)
server/   сервер (Node.js, Fastify, PostgreSQL)
deploy/   развёртывание: Docker Compose, HTTPS, резервные копии
docs/     инструкции
```

- **Посмотреть на телефоне без сервера** — демо-режим: `cd mobile`, `npm install`, `npx expo start`,
  на стартовом экране «Посмотреть демо с примерами данных».
- **С сервером на своём компьютере** — [docs/local-run.md](docs/local-run.md).
- **На настоящем сервере в Казахстане** — [docs/deploy.md](docs/deploy.md).
- **Пилот с настоящими участниками** — [docs/pilot.md](docs/pilot.md): сервер, сборка
  приложения для Android и iPhone, пуш-уведомления, первый поток.

## Проверки

```bash
cd mobile && npx tsc --noEmit && npx eslint src
```
```bash
cd server && npx tsc --noEmit && npm test
```

Тесты сервера по умолчанию идут на встроенной базе; на PostgreSQL —
с переменной `TEST_DATABASE_URL=postgres://…`.

## Сервер: основное API

Вход: `POST /v1/auth/request-code` → `POST /v1/auth/verify` (код из SMS или письма) →
токены; `POST /v1/auth/refresh`.
Участник: `GET /v1/me/state` (всё состояние), заявка `POST /v1/me/join`, данные —
`/v1/me/tasks`, `/statements`, `/steps`, `/fitness`, `/goals`, `/interim`.
Модератор: `/v1/mod/overview`, `/v1/mod/requests`, `/v1/mod/streams/:id/members`,
`/v1/mod/members/:id` (досье), `POST /v1/mod/members/:id/tasks`, `/v1/mod/streams/:id/broadcasts`,
`PATCH /v1/mod/streams/:id`, `POST /v1/mod/memberships/:id/approve|reject|block|unblock`.

2. ✅ Сервер: вход по SMS и почте, потоки и заявки, синхронизация данных, пуш при решении
   по заявке, Docker и инструкция по развёртыванию.
   Пуш-уведомления на телефоне, иконка, настройка сборки через EAS.
3. ✅ Анализы: замеры, бланки (фото/PDF), ручной ввод 46 показателей с нормами (по полу и фазе цикла),
   статусы, «Мои анализы», динамика, индекс здоровья 60/25/15, журнал доступа модераторов.
   Нормы взяты из презентации — **перед пилотом их проверяет врач** (`server/src/analyses/catalog.ts`).

4. ✅ Кабинет модератора: потоки, заявки, участники со статусами, досье, задача участнику,
   рассылка, настройки потока, утренние и вечерние напоминания.
6. ✅ Голосовые утренние заявления: запись до 2 минут, прослушивание участником и модератором. Позже: команда модераторов,
   физнормативы, сроки целей.
5. ИИ: распознавание бланков и шагов, сводки и рекомендации.
