# Кактус — мобильное приложение (Android и iOS)

Цели, ежедневные задачи и прогресс участников под контролем модератора.
Написано на Expo (React Native + TypeScript): один код для Android и iOS.

## Запуск

```bash
npm install
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** на телефоне (Android или iPhone).

Для проверки без сервера:
- код потока `VPNWTM` — заявку одобрят со второй проверки статуса;
- код `OTKAZZ` — заявку отклонят;
- на стартовом экране есть «Посмотреть демо с примерами данных».

## Проверки

```bash
npx tsc --noEmit
npx eslint src
```

## Структура

```
src/
  app/            экраны (Expo Router: каждый файл — маршрут)
    (tabs)/       вкладки участника: Сегодня, Цели, Прогресс, Профиль
  components/     составные блоки экранов
  ui/             базовые компоненты: кнопки, поля, карточки, диалоги
  theme/          цвета и типографика (тёмная тема по макетам)
  data/
    types.ts      модели данных
    store.tsx     состояние приложения и действия, хранение на устройстве
    mock-server.ts  имитация сервера — заменяется HTTP-клиентом на этапе 2
    demo.ts       демо-данные
  lib/            даты, подсчёт прогресса
```

## Этапы

1. **Готово:** онбординг (согласие, вход по коду, заявка, анкета), «Сегодня», утреннее
   заявление (текст), задачи внутри целей, план дня, шаги и физнормативы, цели и цели на срок,
   прогресс, профиль, согласие и переключатель ИИ, выход из потока, удаление аккаунта.
2. Бэкенд: аккаунты (телефон/e-mail вместо Telegram), потоки и заявки, синхронизация,
   пуш-уведомления вместо бота, голосовые заявления.
3. Анализы: загрузка бланков, 46 показателей, индекс здоровья, экспорт.
4. Кабинет модератора: потоки, заявки, досье, настройки, рассылки, доступ.
5. ИИ: распознавание бланков и шагов, сводки и рекомендации.
