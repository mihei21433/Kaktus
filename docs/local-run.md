# Запуск на своём компьютере (Windows / Mac)

Сервер и приложение работают на вашем компьютере, телефон подключается к ним по Wi-Fi.
Это бесплатно, данные остаются на компьютере (в папке `server/data`).

Нужно: Node.js LTS (https://nodejs.org), приложение **Expo Go** на телефоне,
телефон и компьютер в **одной Wi-Fi сети**.

На Windows все команды выполняйте в **командной строке** (`cmd`), а не в PowerShell.

## 1. Сервер — первое окно

Откройте папку проекта → папку `server`, в адресной строке проводника введите `cmd`, Enter.

```bash
npm install
```

Сделайте себя модератором (один раз). Впишите номер, с которым будете входить:

```bash
npm run admin -- make-moderator +77011234567 "Ваше имя"
```

Запустите сервер:

```bash
npm run dev
```

Окно не закрывайте. **Windows спросит разрешение для Node.js** — поставьте галочку
«Частные сети» и нажмите «Разрешить», иначе телефон не достучится до сервера.

## 2. Приложение — второе окно

Откройте папку `mobile`, введите `cmd` в адресной строке:

```bash
npm install
```

```bash
npx expo start
```

Отсканируйте QR-код: на Android — в Expo Go, на iPhone — камерой.

## 3. Модератор

1. Примите согласие → «Уже есть аккаунт — войти».
2. Введите номер из шага 1 → «Получить код». SMS в тестовом режиме не отправляются:
   код показан прямо на экране в жёлтой плашке.
3. Откроется кабинет модератора: «Потоки» → «+» → создайте поток и запишите **код**.

## 4. Участник

Участником удобно войти со второго телефона (или выйти из модератора: «Настройки» →
«Выйти из аккаунта»). Вход — по **другому** номеру, затем «Вступить по коду» и код потока.
Заявка появится у модератора во вкладке «Заявки».

Анализы: модератор открывает замер в «Настройки потока» → «Замеры анализов» — у участников
на «Сегодня» появится просьба сдать анализы, загрузить бланк и ввести значения.

Что умеет модератор: одобрять заявки, смотреть участников со статусами (по плану,
отстаёт, без отправок, новый), открывать досье, ставить задачу участнику с комментарием,
блокировать, делать рассылку, менять настройки потока и выпускать новый код.

## Команды администратора

Нужны редко (например, назначить модератора). **Перед командой остановите сервер**
(`Ctrl+C` в его окне), после — запустите снова `npm run dev`.

```bash
npm run admin -- streams
```
```bash
npm run admin -- requests
```
```bash
npm run admin -- approve <id заявки из списка>
```
```bash
npm run admin -- reject <id заявки>
```

## Если не работает

- **«Нет связи с сервером»** — сервер не запущен, Windows не разрешил доступ (Панель
  управления → Брандмауэр → Разрешить приложению… → Node.js → «Частные»), или телефон
  в другой сети (гостевой Wi-Fi часто изолирует устройства).
- **Expo в режиме `--tunnel`** — приложение не найдёт сервер само. Запустите так
  (впишите IP компьютера, его покажет команда `ipconfig`):
  `set EXPO_PUBLIC_API_URL=http://192.168.1.5:3000 && npx expo start --tunnel`
- **Начать с чистого листа** — остановите сервер и удалите папку `server/data`.
