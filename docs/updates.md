# Обновление приложения без нового APK

Изменения экранов, текстов и логики доставляются на телефоны «по воздуху» (EAS Update):
приложение само скачивает новую версию при запуске, а когда она готова, показывает внизу
плашку **«Загружено обновление — Перезапустить»**. В профиле есть строка **«Версия приложения»**
с кнопкой ручной проверки.

## Как выпустить обновление

1. Скачайте свежий ZIP проекта с GitHub и распакуйте в **новую** папку.
2. Откройте `cmd` в папке `mobile`:

```bash
npm install
```

```bash
set EAS_NO_VCS=1
```

```bash
npx eas-cli@latest update --channel preview --environment preview --message "Что изменилось"
```

Через пару минут обновление на сервере Expo. Участники получат его при следующем открытии
приложения (или сразу — кнопкой «Версия приложения → проверить»).

Для сборок из профиля `production` (iPhone, TestFlight) — то же с `--channel production --environment production`.

## Когда всё-таки нужен новый APK

Когда меняется «нативная» часть: новое разрешение (камера, микрофон…), новый модуль телефона,
обновление версии Expo. Приложение защищено: обновление, которому нужен новый APK, на старую
установку **не придёт** и ничего не сломает. Если после `update` никто не получил изменения —
значит, нужна новая сборка:

```bash
npx eas-cli@latest build --platform android --profile preview
```

Разработчик всегда напишет, нужен ли для изменений новый APK или хватит обновления.

## Что важно знать

- Обновление содержит только код и картинки приложения — данных участников в нём нет.
  Хранится на серверах Expo.
- Адрес сервера (`https://api.vectorfamily.kz`) записан в самом приложении, поэтому обновления
  работают без дополнительных настроек.
- Бесплатный тариф Expo покрывает пилот; лимиты — на https://expo.dev/pricing.
