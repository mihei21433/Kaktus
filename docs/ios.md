# iPhone

## Сейчас: веб-версия — https://app.vectorfamily.kz

Тот же «Кактус», открывается в Safari. Чтобы он выглядел и запускался как приложение:
**«Поделиться» → «На экран „Домой“»** (подсказка появляется сама при первом входе).

Работает всё, кроме пуш-уведомлений (их на iPhone даст TestFlight или отдельная доработка веб-пушей).
Запись голоса — пока экран включён; при сворачивании Safari останавливает запись.

Обновляется сама: каждое изменение в `main` после автотестов собирается в ветку `production-web`,
сервер забирает её раз в 2 минуты (`deploy/auto-update.sh`). Файлы сайта — только код приложения,
данных участников в них нет; данные — на сервере в Казахстане.

Один раз: в hoster.kz → «Управление ресурсными записями» добавить **A-запись `app` → 89.126.200.90**
(так же, как `api`). Сертификат HTTPS Caddy выпустит сам.

## Дальше: настоящее приложение через TestFlight

Нужен аккаунт Apple Developer Program — $99 в год:
https://developer.apple.com/programs/enroll/ (Apple ID с двухфакторной защитой; «Individual» —
без регистрации компании; проверка 1–2 дня). Когда аккаунт одобрят — разработчик подскажет,
какой ключ App Store Connect создать и куда его положить, дальше сборки и выкладка в TestFlight идут сами.
