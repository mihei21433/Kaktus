# Пилотный запуск

Цель: настоящий сервер в Казахстане и приложение «Кактус» на телефонах первых участников.
Порядок важен — каждый шаг опирается на предыдущий.

## Что понадобится

| Что | Зачем | Стоимость |
|---|---|---|
| VPS в Казахстане + домен | сервер и база | ~8–12 тыс. ₸/мес + ~3–5 тыс. ₸/год |
| Mobizon | SMS с кодом входа | за каждое SMS |
| Аккаунт expo.dev | сборка приложения, пуш-уведомления | бесплатно |
| Проект Firebase | пуш-уведомления на Android | бесплатно |
| Apple Developer | приложение на iPhone (TestFlight) | 99 $/год |

## 0. Юридическое — до приглашения людей

Текст согласия содержит заглушки: `[НАИМЕНОВАНИЕ ОПЕРАТОРА]`, `[БИН]`, `[АДРЕС]`, `[EMAIL]`,
`[ТЕЛЕФОН]`, `[НАЗВАНИЕ ПОСТАВЩИКА]`, `[СТРАНА]`, `[СРОК]`, `[СРОК ХРАНЕНИЯ БЛАНКОВ]`.
Их заполняет юрист — файл `mobile/src/data/consent-text.ts`. **Не приглашайте участников, пока
заглушки на месте.** Если текст меняется после запуска — поменяйте `CONSENT_VERSION`
в `mobile/src/data/mock-server.ts` (например, на дату новой редакции).

## 1. Сервер

Разверните сервер по [deploy.md](deploy.md). Результат — адрес вида
`https://api.ваш-домен.kz`, на котором открывается `{"ok":true}` по адресу `/health`.

Назначьте себя модератором:

```bash
docker compose exec api node dist/admin.js make-moderator +77011234567 "Ваше имя"
```

## 2. Адрес сервера в приложении

Уже прописан: `https://api.vectorfamily.kz` (файл `mobile/eas.json`). Если адрес сервера
когда-нибудь изменится — поменяйте его там в двух местах и соберите приложение заново.

## 3. Аккаунт Expo

Зарегистрируйтесь на https://expo.dev. Затем в командной строке (`cmd`) в папке `mobile`:

```bash
npm install
```

```bash
npx eas-cli@latest login
```

```bash
npx eas-cli@latest init
```

`init` создаст проект на expo.dev и запишет его номер (`projectId`) в настройки. Если появится
предупреждение, что номер нельзя записать автоматически, — откройте `mobile/app.json` и
добавьте внутрь `"expo": { … }` строку, которую покажет команда, в таком виде:

```json
"extra": { "eas": { "projectId": "номер-из-команды" } }
```

## 4. Пуш-уведомления на Android (Firebase)

Без этого шага приложение работает, но уведомления на Android не приходят.

1. https://console.firebase.google.com → «Создать проект» (Google Analytics можно выключить).
2. В проекте: «Добавить приложение» → Android → имя пакета **`app.kaktus.mobile`** → скачайте
   **`google-services.json`** и положите его в папку `mobile` (рядом с `app.json`).
3. В Firebase: ⚙ Настройки проекта → «Сервисные аккаунты» → «Создать закрытый ключ» →
   скачается JSON-файл. **Это секрет** — никому не пересылайте и не кладите в репозиторий.
4. На https://expo.dev → ваш проект → **Credentials** → Android → `app.kaktus.mobile` →
   **FCM V1 service account key** → загрузите файл из пункта 3.

На iPhone отдельной настройки не нужно — при первой сборке для iOS программа сама предложит
настроить уведомления, отвечайте «Yes».

## 5. Приложение для Android (APK)

```bash
npx eas-cli@latest build --platform android --profile preview
```

Сборка идёт в облаке Expo 10–20 минут. В конце появятся ссылка и QR-код — по ним APK
скачивается на телефон. При установке Android попросит разрешить установку из этого источника —
разрешите. Ссылку можно разослать участникам пилота.

## 6. Приложение для iPhone (TestFlight)

Нужен аккаунт Apple Developer (https://developer.apple.com/programs/, одобрение — до 1–2 дней).

```bash
npx eas-cli@latest build --platform ios --profile production
```

Программа попросит войти в аккаунт Apple и сама создаст сертификаты. Затем:

```bash
npx eas-cli@latest submit --platform ios
```

Через 10–30 минут сборка появится в App Store Connect → TestFlight. Добавьте участников
по e-mail во «Внешнее тестирование» — им придёт приглашение установить TestFlight и «Кактус».
Первая сборка для внешних тестировщиков проходит короткую проверку Apple (обычно до суток).

## 7. Первый поток

1. Откройте приложение, примите согласие → «Уже есть аккаунт — войти» → ваш номер.
2. «Потоки» → «+» → создайте поток → «Поделиться» кодом с участниками.
3. Участники: установить приложение → «Вступить по коду» → свой номер → код потока.
4. Заявки появятся во вкладке «Заявки» — одобряйте, участникам придёт уведомление.

## Обновления

- **Сервер** — по [deploy.md](deploy.md), раздел «Обновление». Пользователи ничего не замечают.
- **Приложение** — новая сборка (шаги 5–6). На Android участники ставят новый APK поверх
  старого, на iPhone TestFlight обновляет сам. Данные не теряются — они на сервере.

## Если что-то не так

- **SMS не приходит** — проверьте баланс Mobizon и журнал сервера:
  `docker compose logs api --tail 50`.
- **«Нет связи с сервером»** в приложении — проверьте адрес в `eas.json` (шаг 2) и что
  `https://ваш-адрес/health` открывается в браузере телефона. После правки адреса нужна новая сборка.
- **Уведомления не приходят** — пуши работают только в собранном приложении (не в Expo Go),
  участник должен разрешить уведомления при первом входе; для Android — шаг 4.
